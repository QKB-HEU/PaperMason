# Code of Conduct

PaperMason is a collaborative project for researchers and software builders.
Participate with respect, assume good intent, and keep criticism focused on
ideas, evidence, and code rather than people.

Harassment, discrimination, personal attacks, and publication or licensing
misrepresentation are not acceptable. Project maintainers may remove comments,
issues, pull requests, or participation that violate these expectations.

To report a concern privately, contact the repository maintainer through the
contact method listed on the repository profile. Do not include private PDFs,
personal library paths, credentials, or unpublished research in a public
report.
